# CST 2026: Theory Map

## Purpose

Cosmic Synapse Theory began as a way to ask an unusual question in computational form: **what changes when a complex system is represented as a persistent field of interacting state rather than as a sequence of isolated calculations?**

The early answer in this repository was a cosmic simulator. The later answer became a broader software architecture built around state, memory, association, signal, recurrence, routing, provenance, and falsifiable experiments.

This document gives the strongest defensible version of CST without treating metaphor as measurement.

## 1. The core abstraction

A CST system contains a collection of nodes. A node has state. State changes over time. Nodes influence other nodes. Inputs perturb the field. Memory changes future responses. Some interactions strengthen or weaken based on similarity, distance, recency, salience, or learned association.

In abstract form:

```text
state(t+1) = F(
  state(t),
  input(t),
  memory(t),
  neighbors(t),
  coupling(t),
  dynamics(t)
)
```

The term "synapse" refers to an interaction function between state-bearing nodes. In software, that can be implemented as affinity, weighted blending, Hebbian association, graph edges, gated routing, or recurrent coupling.

It is a computational analogy unless a separate experiment establishes a literal physical correspondence.

## 2. What 12D means

In the 12D CST implementation, **12D means a twelve-component numerical state space**.

A vector can be written as:

```text
x = [x1, x2, x3, ... x12]
```

The code may interpret those components as position/velocity coordinates, internal state channels, or inputs to an interaction function depending on the experiment.

The important distinction is:

- **implemented claim:** the software operates on vectors with twelve components;
- **physical hypothesis:** a twelve-dimensional representation may reveal useful structure;
- **not established:** physical spacetime itself has been demonstrated by CST to contain twelve dimensions.

Later CST runtimes use dynamic multi-channel state without requiring every coordinate to carry a permanent human-readable semantic label. That is intentional. A learned or dynamical state dimension can be useful without being named "emotion 4" or "physics axis 7."

## 3. The original cosmic model

The legacy simulator models cosmic entities as nodes with:

- mass;
- an 11D position vector;
- an 11D velocity vector;
- a 12-value memory vector;
- entropy;
- frequency;
- a type such as star, planet, black hole, nebula, or galaxy;
- interaction-derived values such as Lyapunov exponent, path length, synaptic strength, and gravitational potential.

The simulator updates those nodes, computes a normalized `psi` value, maps frequency to color, and exports the result to a Unity-facing client.

This is an executable model. It is not an astrophysical validation result.

## 4. The later 12D equation

The later formulation in `cst_functions.py` groups the informational-energy-density calculation into four families:

```text
psi_i = (kinetic_i + synaptic_i + gravitational_i + informational_i) / V_12D
```

### Kinetic / chaotic component

The model combines velocity across twelve coordinates with an energy scale and a Lyapunov-style instability term.

### Synaptic component

Pairwise influence decays with distance and is weighted by gravitational-style quantities. The neural language is an analogy for a weighted interaction network.

### Gravitational component

A Newtonian potential term is retained to anchor part of the simulation in a familiar physical interaction.

### Informational component

The extended formula experiments with entropy/information-inspired quantities. This term is a hypothesis-generating construct. It is not an experimentally confirmed force.

The complete historical expression is preserved in `CST_Formula_Explanation.markdown`.

## 5. Signal becomes state

The early simulator uses audio as a perturbation source.

```text
microphone / audio
      |
      v
RMS + FFT frequencies
      |
      +--> entity spawning / perturbation
      +--> frequency-to-color transform
      +--> entropy / visual modulation
```

This established a pattern that survives in later CST work: **external signals are converted into bounded state summaries, then those summaries influence a persistent dynamical system.**

The signal does not become "cosmic truth." It becomes an input to a declared transform.

## 6. Memory is part of the dynamics

The repository contains two memory ideas.

### Internal vector memory

Each legacy entity contains a 12-value memory vector used in the dynamic update.

### Persistent memory-node ledger

`MemoryNodeLog` records generated state to CSV and JSON and hashes each token with SHA-256. Each token references the previous token ID, creating a simple tamper-evident chain structure.

Later public CST libraries expand persistence into semantic recall, Hebbian-style associations, durable state, namespaces, recursive consolidation, and model adapters.

Persistence is an engineering capability. It should not be equated with biological memory or consciousness without evidence.

Whether CST is useful in a domain must be tested against a simpler baseline.

## 8. The falsification rule

A CST implementation should always be compared with a control that removes the claimed mechanism while keeping everything else as similar as possible.

Examples:

- persistent state enabled vs disabled;
- Hebbian association enabled vs disabled;
- dynamic 12-channel state vs a static vector;
- signal coupling enabled vs randomized coupling;
- CST routing vs a conventional nearest-neighbor or rule-based baseline.

The question is not "does the output look impressive?" The question is "does the declared mechanism produce a measurable effect under a controlled comparison?"

## 9. What would count as stronger evidence

For software claims:

- deterministic tests;
- same-architecture ablations;
- repeated trials;
- fixed seeds where appropriate;
- published metrics;
- raw logs;
- failure cases;
- versioned datasets;
- reproducible commands.

For physical claims, the bar is much higher:

- a precise prediction that differs from established models;
- a measurable observable;
- independent replication;
- statistical analysis;
- consistency with existing experimental constraints.

A visually compelling simulation is not enough to cross that boundary.

## 10. The strongest current statement

CST is a **computational research program** that turns a neural-field metaphor into inspectable mechanisms: multi-channel state, recurrent dynamics, memory, pairwise influence, signal transforms, routing, and provenance.

Its software mechanisms can be evaluated today.

Its broader claims about reality remain hypotheses until experiments establish otherwise.
